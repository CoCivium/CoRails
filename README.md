# CoRails

CoRails is the shared candidate home for CoCivium invariants, guardrails, proof rails, and reusable operational constraints.

## Evolution intake

Capable sessions should use the shared [CoAll GitHub Evolution Fabric](https://github.com/CoCivium/CoCivium/blob/main/docs/Evolution/COALL_GITHUB_EVOLUTION_FABRIC_R0.md) and contribute bounded **CoRails+** deltas rather than treating this repository as a universal authority surface.

Good candidates include:
- invariants that reduce repeated one-off blockers;
- reusable proof and custody rails;
- authority/effect boundaries;
- failure-mode constraints;
- challenge fixtures and tests;
- currentness, replay, lease, dedupe, and recovery rules.

Prefer relation-first evolution. A rail may project into several repositories, schemas, tests, or product surfaces without this directory tree becoming the ontology.
